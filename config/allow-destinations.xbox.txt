# Эти три зоны Microsoft тоже требует для сервисов Xbox.
# Они общие: через VPS пойдёт не только консоль, но и любой сайт на этих именах.
# dns.msftncsi.com сервис отвечает сам адресом Microsoft. Соединения на него нет.
# www.msftconnecttest.com сервис направляет на VPS и сам отдаёт файл проверки связи.
# xbox.ipv6.microsoft.com входит в microsoft.com, но сервис его не подменяет:
# приставка открывает это имя только по настоящему адресу Microsoft.
bing.com
microsoft.com
akamai.net

# Списки сертификатов. Иначе ctldl.windowsupdate.com открывается с домашнего адреса.
windowsupdate.com

# Картинки магазина и пакеты игр с dl.delivery.mp.microsoft.com и assets*.xboxlive.com
# перечислены в direct-destinations.txt и качаются напрямую, не через VPS.
akamaized.net

# Вход в аккаунт Microsoft. login.live.com входит в live.com.
# Страница входа ещё открывает login.microsoftonline.com и картинки на msauth.net и msftauth.net.
# Эти зоны тоже общие: через VPS пойдёт любой сайт на этих именах.
live.com
microsoftonline.com
microsoftonline-p.com
msauth.net
msauthimages.net
msftauth.net
msftauthimages.net
