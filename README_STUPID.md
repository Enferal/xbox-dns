# Тест Xbox. Куда нажимать

Три инструкции, от короткой к самой подробной:

1. [README.md](README.md) — коротко, если команды уже знакомы
2. [README_EASY.md](README_EASY.md) — простыми словами
3. [README_STUPID.md](README_STUPID.md) — куда нажимать, по шагам

Нужна Ubuntu 22.04 или 24.04 и адрес сервера. Ниже он называется `IP_СЕРВЕРА`. Вместо этих слов пиши свой адрес, например `203.0.113.10`. Заходи как root.

На шаге 4 скрипт сам смотрит, стоят ли `python3`, `iproute2`, `ca-certificates`, `bind9-dnsutils`, `ufw` и `git`. Нет пакета — поставит и напишет `Ставлю недостающее`. Всё уже есть — напишет `Все нужные пакеты уже стоят` и ничего качать не будет. Git нужен раньше, на шаге 2.

В конце на телефоне меняется только DNS. Прокси не включай.

## 1. Зайди на сервер

Открой программу, которой заходишь на сервер. Вставь и нажми Enter:

```bash
ssh root@IP_СЕРВЕРА
```

Спросит пароль. При вводе его не видно. Так и должно быть. Набери пароль и нажми Enter. Дальше все команды пиши здесь, пока не напишешь `exit`.

## 2. Скачай проект

Команды только скачивают программу с GitHub. Остальные файлы сервера не трогают.

```bash
apt-get update
apt-get install -y git
git clone https://github.com/Enferal/xbox-dns.git /opt/egress-proxy
```

## 3. Порты свободны?

```bash
ss -tulpn 'sport = :53 or sport = :80 or sport = :443'
```

В списке только `127.0.0.53:53` — хорошо, иди к шагу 4.

Есть `*:443` или `0.0.0.0:443` — порт занят другой программой. Xbox через сервер не откроется, пока она работает. Останови её и проверь ещё раз. Строки `127.0.0.53` не трогай.

## 4. Поставь службу

```bash
cd /opt/egress-proxy
sh deploy/install-native.sh
```

Первая строка: `Установщик egress-proxy. Пустой ALLOW_CLIENTS пускает всех.` Её нет, и сразу пошёл список пакетов — снова шаг 2, потом этот. Недостающие программы скрипт ставит сам, после вопросов.

Дальше вопросы.

- Спросит, удалять ли старые настройки. Жми Enter.
- На остальные вопросы тоже жми Enter.

Дождись конца. Найди строку:

```text
На устройстве укажите DNS: 203.0.113.10
```

Число в ней — адрес сервера. Запиши. Он нужен на телефоне.

Если вместо этого написано, что DNS не ответил, сохрани последние строки с экрана. Команда для них есть ниже.

## 5. Включи тест Xbox

Четыре команды копируют готовый тест. Тоже на сервере:

```bash
cp /opt/egress-proxy/.env.xbox.test /etc/egress-proxy/egress.env
cp /opt/egress-proxy/config/allow-destinations.xbox.txt /etc/egress-proxy/allow-destinations.txt
printf '%s\n' auto > /etc/egress-proxy/exit-ips.txt
systemctl restart egress-proxy
```

В тесте `ALLOW_CLIENTS` пустой. Сервис отвечает любому устройству. Адрес телефона заранее знать не надо.

## 6. Сервер отвечает?

```bash
dig +short @127.0.0.1 user.auth.xboxlive.com A
```

Должна быть одна строка: адрес твоего сервера. Тот же, что записал в шаге 4.

Пусто или `connection refused` — смотри журнал:

```bash
journalctl -u egress-proxy -n 40 --no-pager
```

Пока `dig` не показывает адрес сервера, на телефоне ничего не меняй.

## 7. DNS на телефоне

Открой настройки Wi‑Fi той сети, где сидит телефон.

DNS поставь вручную. Впиши адрес сервера из шага 4. Второе поле можно оставить пустым. Прокси не включай.

Выключи Wi‑Fi и включи снова.

## 8. Xbox идёт через сервер?

На сервере:

```bash
journalctl -u egress-proxy -f
```

Открой на телефоне приложение Xbox или сайт `xbox.com`. На сервере должны появляться строки `Прокси ...`. Запрос прошёл через сервер, сайт видит адрес сервера, а не телефона.

Закрыть журнал: `Ctrl+C`.

## Не работает

Служба молчит:

```bash
systemctl status egress-proxy --no-pager
```

Строки `Отказ DNS клиенту` в этом тесте быть не должно: пускать можно всех. Такая строка есть — шаг 5 не применился. Сделай его ещё раз.

Сайты Xbox не открываются, а `dig` в шаге 6 показывает адрес сервера. На телефоне не тот DNS, или порт 443 на сервере занят. Повтори шаг 3.

DNS на сервере есть, а строк `Прокси` нет. Режет домашний роутер. Команды ниже пиши там, где приглашение `root@OpenWrt`. На VPS их нет. Подробно: [ROUTER.md](ROUTER.md).

Роутер обычный, не OpenWrt. Ещё раз впиши в DNS устройства адрес сервера. На роутере для этой приставки выключи родительский контроль, свой DNS, прокси и VPN.

Роутер OpenWrt. Ошибка `0x800704c6` значит, что приставка до Xbox не дошла. На роутере по очереди:

```bash
grep -qx IP_СЕРВЕРА /opt/zapret/ipset/zapret-ip-user-exclude.txt || echo IP_СЕРВЕРА >> /opt/zapret/ipset/zapret-ip-user-exclude.txt
nft add element inet zapret nozapret '{ IP_СЕРВЕРА }'
iptables -t mangle -S XRAY
```

В последней команде есть `TPROXY` и MAC приставки — сотри правило. Скопируй строку, замени `-A` на `-D` и выполни. Потом выключи скрипт, который возвращает правило после перезагрузки:

```bash
line=$(uci show firewall | grep "path='/etc/firewall.xraytproxy'")
sec=${line%%.path=*}
uci set "${sec}.enabled=0"
uci commit firewall
uci show "$sec"
```

Должно быть `enabled='0'`. Файрвол не перезапускай. Выдерни питание приставки на 10 секунд и снова открой магазин.

Голос и часть мультиплеера могут не работать. Через этот тест идёт обычный интернет на портах 80 и 443, не UDP.

Закачка игр идёт сразу с домашнего адреса, не через сервер. В журнале это `закачка напрямую`. Вход и магазин идут через сервер.

Пока на телефоне этот DNS, через сервер идут и обычные сайты Microsoft, Bing и Live. Вернуть как было: в Wi‑Fi поставь DNS на «автоматически».
