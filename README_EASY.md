# Как поставить, простыми словами

Проект: https://github.com/Enferal/xbox-dns

Нужна Ubuntu 22.04 или 24.04. На сервер заходите как root. На телефоне или приставке потом меняется только DNS. Прокси там включать не нужно.

Если команды хочется короче, есть [README.md](README.md). Если хочется совсем по кнопкам, есть [README_STUPID.md](README_STUPID.md). Роутер OpenWrt настраивается по [OPENWRT.md](OPENWRT.md). Когда пакет до сервера пропадает, смотрите [ROUTER.md](ROUTER.md).

Ниже вместо `IP_СЕРВЕРА` пишите адрес своего сервера. Вместо `IP_УСТРОЙСТВА` — белый адрес телефона, компьютера или дома, с которого можно пользоваться службой.

Скрипт сам смотрит, стоят ли нужные программы. Нет пакета — поставит и напишет `Ставлю недостающее`. Всё уже есть — напишет `Все нужные пакеты уже стоят`.

## 1. Порты свободны?

Зайдите на сервер:

```bash
ssh root@IP_СЕРВЕРА
ss -tulpn 'sport = :53 or sport = :80 or sport = :443'
```

Только `127.0.0.53:53` — нормально, ставьте дальше.

`*:443` или `0.0.0.0:443` — порт занят другой программой. DNS ответит, а сайты через сервер не откроются, пока она работает.

## 2. Скачать проект

Тоже на сервере. Команды только скачивают программу:

```bash
apt-get update
apt-get install -y git
git clone https://github.com/Enferal/xbox-dns.git /opt/egress-proxy
```

## 3. Поставить

```bash
cd /opt/egress-proxy
sh deploy/install-native.sh
```

Первая строка: `Установщик egress-proxy. Пустой ALLOW_CLIENTS пускает всех.` Если её нет и сразу пошёл список пакетов, на сервере старый скрипт. Повторите шаг 2.

Скрипт спрашивает по очереди.

1. Настройки уже были — спросит, стереть ли их. Enter не стирает. `y` стирает список имён, адреса выхода и файл настроек.
2. Дальше вопросы по одному, с примером. Enter оставляет то, что в строке «Сейчас».
3. На вопросе `DNS_UPSTREAM` Enter берёт DNS самого сервера. Своего DNS на сервере нет — останется `1.1.1.1,8.8.8.8`.
4. `ALLOW_CLIENTS` решает, кто может пользоваться службой. Пустой ответ пускает всех. Знак `-` тоже. В примере может стоять адрес, с которого вы зашли по SSH.

Дождитесь конца. Последняя нужная строка такая:

```text
На устройстве укажите DNS: 203.0.113.10
```

Этот адрес потом вписывается в сеть устройства. Запомните его.

Сразу после установки служба отвечает всем, если на вопросе `ALLOW_CLIENTS` вы ничего не вписали. Шаг 4 нужен, только если доступ захотите сузить потом.

Когда в проекте появятся новые файлы, обновляйте так. Установщик заново не запускайте: он снова задаст вопросы и перезапишет настройки.

```bash
cd /opt/egress-proxy
git pull
install -m 0755 scripts/egress_proxy.py /usr/local/lib/egress-proxy/egress_proxy.py
systemctl restart egress-proxy
```

## 4. Пускать только своих

Откройте файл:

```bash
nano /etc/egress-proxy/egress.env
```

Пускать всех — строку `ALLOW_CLIENTS` не трогайте и идите к шагу 5.

Только свои устройства — допишите адрес:

```bash
ALLOW_CLIENTS=IP_УСТРОЙСТВА
```

Несколько адресов — через запятую, без пробелов:

```bash
ALLOW_CLIENTS=203.0.113.8,198.51.100.20
```

Сохранить: `Ctrl+O`, Enter. Выйти: `Ctrl+X`. Потом:

```bash
systemctl restart egress-proxy
```

Адрес можно не знать заранее. Зайдите с устройства и откройте журнал на сервере. Будет строка `Отказ DNS клиенту 203.0.113.50`. Число в ней и есть нужный адрес. Впишите его и снова выполните `systemctl restart egress-proxy`.

## 5. DNS на устройстве

В сети устройства укажите DNS из шага 3. Второй DNS оставьте пустым. Прокси не включайте.

На обычном роутере для этой приставки выключите родительский контроль, свой DNS, прокси и VPN. Роутер OpenWrt дополнительно настраивается по [OPENWRT.md](OPENWRT.md): иначе магазин молчит с ошибкой `0x800704c6` или `0x80a40401`.

После смены DNS выдерните питание приставки на 10 секунд.

## 6. Проверка

На сервере:

```bash
dig +short @127.0.0.1 user.auth.xboxlive.com A
```

В ответе адрес вашего сервера, тот же, что в шаге 3.

## 7. Журнал

Новые строки сразу:

```bash
journalctl -u egress-proxy -f
```

Выйти: `Ctrl+C`. Последние 100 строк: `journalctl -u egress-proxy -n 100 --no-pager`.

Как читать:

- `Прокси user.auth.xboxlive.com:443 -> …` — запрос прошёл через сервер, сайт видит адрес сервера.
- `Отказ DNS клиенту …` — этот адрес спросил сервер, а в списке его нет. Добавьте его в `ALLOW_CLIENTS`.
- `закачка напрямую` — файл игры идёт с домашнего адреса, не через сервер. Так и задумано для `dl.delivery.mp.microsoft.com` и `assets1.xboxlive.com`.
- `AAAA -> пусто, через прокси IPv6 нет` — у сервера нет IPv6. Приставка продолжает по обычному адресу.

Ничего не запустилось:

```bash
systemctl status egress-proxy --no-pager
```

UFC 5 ходит на другие порты, не только на 443. Их список и строки для файрвола — в разделе «UFC 5» файла [README.md](README.md).
