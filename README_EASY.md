# Как поставить, простыми словами

Три инструкции, от короткой к самой подробной:

1. [README.md](README.md) — коротко, если команды уже знакомы
2. [README_EASY.md](README_EASY.md) — простыми словами
3. [README_STUPID.md](README_STUPID.md) — куда нажимать, по шагам

Проект: https://github.com/Enferal/xbox-dns

Нужна Ubuntu 22.04 или 24.04. На сервер заходите как root. На телефоне или консоли потом меняется только DNS, больше там ничего не трогайте.

Скрипт сам смотрит, стоят ли `python3`, `iproute2`, `ca-certificates`, `bind9-dnsutils`, `ufw` и `git`. Нет пакета — поставит и напишет `Ставлю недостающее`. Всё уже есть — напишет `Все нужные пакеты уже стоят` и заново ничего не скачает. Git нужен ещё до скрипта, чтобы скачать проект: его ставит шаг 2.

Если до сервера запросы не доходят, смотрите домашний роутер. Команды OpenWrt вводите на роутере, не на VPS. Подробно: [ROUTER.md](ROUTER.md).

Обычный роутер. В DNS устройства впишите адрес VPS. Для него выключите родительский контроль, подмену DNS, прокси и VPN на всю сеть.

Роутер OpenWrt. Магазин молчит и пишет `0x800704c6`, когда TCP до VPS не доходит. На роутере два места. Адрес VPS допишите в `/opt/zapret/ipset/zapret-ip-user-exclude.txt` и в набор: `nft add element inet zapret nozapret '{ АДРЕС_VPS }'`. Если `iptables -t mangle -S XRAY` показывает `TPROXY` с MAC приставки, удалите это правило. В файрволе у включения `/etc/firewall.xraytproxy` поставьте `enabled='0'` и сделайте `uci commit firewall`. Без `enabled='0'` перезагрузка роутера включит перехват снова.

Ниже вместо `IP_СЕРВЕРА` пишите адрес своего VPS. Вместо `IP_УСТРОЙСТВА` — адрес телефона, компьютера или консоли, которым можно пользоваться сервисом.

## 1. Порты свободны?

Зайдите на сервер:

```bash
ssh root@IP_СЕРВЕРА
ss -tulpn 'sport = :53 or sport = :80 or sport = :443'
```

Только `127.0.0.53:53` — нормально, ставьте.

`*:443` или `0.0.0.0:443` — порт занят. DNS ответит, а сайты через сервер не откроются, пока та программа работает.

## 2. Скачать проект

Тоже на сервере. Команды только скачивают программу:

```bash
apt-get update
apt-get install -y git
git clone https://github.com/Enferal/xbox-dns.git /opt/egress-proxy
```

## 3. Поставить

```bash
cd /opt/egress-proxy
sh deploy/install-native.sh
```

Первая строка: `Установщик egress-proxy. Пустой ALLOW_CLIENTS пускает всех.` Сразу пошёл список пакетов, без этой строки — на сервере старый скрипт, повторите шаг 2. Недостающие программы скрипт ставит сам, уже после вопросов.

Когда в репозитории появятся новые файлы:

```bash
cd /opt/egress-proxy
git pull
sh deploy/install-native.sh
```

Скрипт спрашивает по очереди.

1. Настройки уже были — спросит, стереть ли их. Enter не стирает. `y` стирает и начинает заново. Пропадут список доменов, адреса выхода и файл настроек.
2. Дальше настройки по одной, с примером. Enter оставляет то, что в строке «Сейчас».
3. `DNS_UPSTREAM` другой. Enter берёт DNS самого VPS. Старый список, если он другой, будет в строке «В файле сейчас»: чтобы оставить его, впишите руками. Своих DNS на сервере нет — Enter оставит `1.1.1.1,8.8.8.8`.
4. `ALLOW_CLIENTS` решает, кто может пользоваться сервисом. Пусто — все. В примере может быть адрес, с которого вы сейчас зашли по SSH. Знак `-` тоже пускает всех.

Дождитесь конца. Последняя нужная строка такая:

```text
На устройстве укажите DNS: 203.0.113.10
```

Этот адрес потом вписывается в сеть устройства. Запомните его.

Сразу после установки сервис отвечает всем, если на вопросе `ALLOW_CLIENTS` вы ничего не вписали. Шаг 4 нужен, только если доступ захотите сузить потом.

## 4. Пускать только своих

Откройте файл:

```bash
nano /etc/egress-proxy/egress.env
```

Пускать всех — эту строку не трогайте, идите к шагу 5.

Только свои устройства — найдите `ALLOW_CLIENTS=` и допишите адрес:

```bash
ALLOW_CLIENTS=IP_УСТРОЙСТВА
```

Несколько устройств — через запятую, без пробелов:

```bash
ALLOW_CLIENTS=203.0.113.8,198.51.100.20
```

Сохранить: `Ctrl+O`, Enter. Выйти: `Ctrl+X`.

Потом:

```bash
systemctl restart egress-proxy
```

Адрес можно не знать заранее. Зайдите с устройства, на сервере откройте журнал. Будет строка `Отказ DNS клиенту 203.0.113.50`. Число в ней и есть нужный адрес. Впишите его в `ALLOW_CLIENTS` и снова `systemctl restart egress-proxy`.

## 5. DNS на устройстве

В сети устройства укажите DNS из шага 3. Прокси не включайте.

## 6. Проверка

На сервере:

```bash
dig +short @127.0.0.1 user.auth.xboxlive.com A
```

В ответе адрес вашего сервера, тот же, что в шаге 3.

## 7. Журнал

Новые строки сразу:

```bash
journalctl -u egress-proxy -f
```

Выйти: `Ctrl+C`.

Последние 100 строк:

```bash
journalctl -u egress-proxy -n 100 --no-pager
```

Как читать:

- `Отказ DNS клиенту …` — этот адрес спросил сервер, а в списке его нет. Добавьте в `ALLOW_CLIENTS`.
- `Прокси user.auth.xboxlive.com:443 -> …` — запрос прошёл через сервер.
- `закачка напрямую` — файл игры идёт с домашнего адреса, не через VPS. Это `dl.delivery.mp.microsoft.com` и `assets1.xboxlive.com`.

Ничего не запустилось:

```bash
systemctl status egress-proxy --no-pager
```
